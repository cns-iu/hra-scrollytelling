# hra-scrollytelling

Learn about the HRA through scrollytelling!

## Preview locally

This is a static site, so there is no build step or dependency installation.

After cloning the repository, open a terminal and run:

```bash
cd hra-scrollytelling
python3 -m http.server 8000
```

Then open the landing page at [http://localhost:8000/index.html](http://localhost:8000/index.html) in a browser.

Keep the terminal running while you preview the site. Press `Ctrl+C` in that terminal to stop the server.
